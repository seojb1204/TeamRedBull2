# 파네스 본편 표시 연결

승인된 파네스 프로토타입의 56개 키포즈를 실제 두 번째 보스 전투에 연결합니다. 미리보기 PR #22를 병합한 최신 main에서 별도 작업했습니다.

공통 수정: ScenePresentation.cs에서 파네스 전용 표시 객체를 생성/전환하고 WorldArtist.cs에서 기존 임시 보스 그림의 중복 표시만 차단합니다. PhanesView/PhanesPose는 기존 게임 상태를 읽으며 이동·피해·판정·DDA·페이즈 규칙을 쓰지 않습니다. 씬/Prefab/컨트롤러 변경이 없습니다.

현재 main에 존재하는 여섯 패턴 orb/fan/beam/rain/barrier/pulse에 각각 양손 광탄/성운 시전/빛 기둥/낙하 시전/결계 유지/지면 레이저 자세를 연결했습니다. 문서의 11개 공격을 새 게임 기능으로 추가하지 않았습니다. 기존 투사체·공격 예고·결계 이펙트와 패링 표시를 유지합니다. 대기·피격·그로기·사망은 실제 상태로 선택합니다. 결과 화면에서도 사망 애니메이션이 끝까지 진행되고 전투 시간이 멈추면 동작도 멈춥니다.

아라쿠스와 동일한 몸 높이 2.2 Unity 단위를 기준으로 런타임 Sprite PPU를 계산합니다. 부유 위치는 기존 시뮬레이션의 boss 좌표를 사용합니다. 텍스처는 Point, 압축/밉맵 없음입니다. 생성 도트의 각도·프레임 정렬·팔레트는 추가 아트 정제가 가능합니다.

검증: 실제 DB 설정을 제외한 독립 복사본에서 Unity 6000.4.0f1 컴파일, 프로덕션 씬의 실제 SpriteRenderer/Resources와 카메라 출력 검사 131개 통과. 56프레임 로딩, 여섯 패턴별 준비/타격/회복, 좌우 반전, 일시정지 시간, 결계 유지, 피격·그로기·결과 사망, 다른 보스 전환과 2.2 크기를 확인했습니다. Windows 빌드 성공. 수동 보스전 완주와 실제 DB 연동은 미검증입니다.

복구: 이 PR의 merge commit을 revert하면 이전 표시로 돌아갈 수 있습니다. 기존 에셋과 게임 데이터를 삭제하지 않았습니다.

Windows 확인 추가: 로비 19개 통과. 별도 진단 빌드에서 파네스 보스전 진입과 56프레임 로딩, 실제 SpriteRenderer 출력 확인. 2층 해금은 검증용 격리 저장에서만 설정했고 진단 스크립트는 PR에 포함하지 않습니다. 자동 보고서 시작 HP는 처음 시작한 아라쿠스 값이므로 파네스 전투 성과로 해석하지 않습니다. 화면은 UI를 제외한 실제 월드 카메라 출력입니다.
