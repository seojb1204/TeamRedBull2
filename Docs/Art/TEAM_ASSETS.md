# 팀 제공 아라쿠스 자료

원본: 사용자 제공 Arakus_PixelSprites.zip (2026-11-02 확인).

사용자는 이 자료가 팀 제작물이며 공개 GitHub 업로드 가능하다고 확인했다. Assets/Art/Arakus의 PNG14장에 적용된다. 이는 CC0나 제3자에 대한 무제한 재배포 라이선스를 뜻하지 않는다. 권리 문의와 추가 사용 허가는 팀에 확인한다.

제공 README는 스크립트/메타가 포함된 별도 프로젝트를 설명하지만 이번 ZIP에는 그 파일이 없다. 현재의 연결 코드는 이 저장소에 맞게 독립적으로 작성했다.

기존 Hero Knight/배경/음원은 Assets/StreamingAssets/CREDITS.md와 동봉 라이선스를 따른다. Assets/Art/Player는 같은 Hero Knight PNG의 에디터 임포트 사본이다.
