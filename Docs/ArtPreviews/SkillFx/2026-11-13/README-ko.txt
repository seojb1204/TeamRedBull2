역전의 탑 신규 스킬 이펙트 후보 3종

기존 패링은 유지. 본편/보스/플레이어 판정/애니메이션/배포는 수정하지 않았습니다.
GIF는 소재 프레임만 재생한 미리보기이며 실제 게임에 적용한 영상이 아닙니다.
아라쿠스 착지: 붉은 갈색 충격파와 돌 파편, 먼지. 288x208 셀 97샘플, 3.2초.
플레이어 W: 청록색 원형 회전 검기. 208x104 셀 25샘플, 0.8초.
플레이어 E: 청백색 큰 내려베기와 착지 파편. 208x116 셀 58샘플, 1.9초.
모두 30fps, PNG는 투명 RGBA, 캐릭터 없음. GIF 끝에는 반복 사이 0.6초 쉼.
각 GIF는 같은 640x520 캔버스와 2배 픽셀 확대. 게임 실제 크기를 의미하지 않습니다.

Unity 수동 가져오기:
Texture Type Sprite (2D and UI), Multiple, Point, Compression None, Mip Maps Off.
착지 시트는 2592x2288이라 Max Size 4096 이상, 나머지는 2048 이상 권장.
해당 셀 크기로 Grid By Cell Size하고 JSON 프레임 순서대로 실제 프레임 수만 사용.
애니메이션 Samples 30, Loop Off. 빈 마지막 칸은 제외.
픽셀 앵커는 JSON meta.pixelfx.pivot(왼쪽 위 기준). Unity 정규화 값은 verified-metadata.json 참고.
이 효과들은 캐릭터 바닥/발 위치 기준 앵커입니다. 스프라이트 중심으로 임의 배치하지 마세요.
한 시트에 전경과 후경을 합친 초안입니다. W 회전 검기를 캐릭터 뒤/앞으로 나눌 경우 별도 레이어 작업 필요.

기존 게임과 연결 전 검토:
착지 공격은 실제 착지 순간에만 시작. 3.2초 먼지 잔상 전체가 공격 판정이라는 뜻이 아님.
W 게임 타격은 동작 시작 +0.35초. 새 소재의 고리 완성 피크는 소재 +0.17초여서 재생 시작 오프셋을 맞춰야 함.
E 게임 타격은 동작 시작 +0.7초. 새 소재 타격 피크는 +0.335초여서 시작 오프셋 약0.365초가 후보.
게임 dt/히트스톱/애니메이션 속도에 따라 실제 씬에서 재검증해야 하며 현재는 적용하지 않음.
W/E 잔광은 기존 회피가능 시점·판정 범위를 가리거나 오해하게 만들지 않도록 조절 필요.
