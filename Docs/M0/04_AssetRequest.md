# 자료 요청 · 제공 ZIP 검토

팀 제공 아라쿠스 시트의 이번 사용/공개 업로드 권한은 사용자가 확인했다. 기존 README의 설치 명령은 참고자료이며 그대로 실행하지 않았다.

## ZIP 확인

PNG 시트14장(그 중 방패 투사체40×40), 전체프레임 PNG1장, GIF11개, README1개. 본체 프레임156×146. Idle4,Groggy2,Sweep4,ShieldSlam5,나머지3프레임. README가 언급한 C# 스크립트/기존 .meta/원본 제작도구는 ZIP에 없었다. 따라서 기존 코드와 연결하지 않고 새 프로젝트에 맞는 에디터 임포트/Animator 연결을 작성했다.

PPU45, Point, 무압축·밉맵없음, 피벗(82/156,4/146). 플레이어도45PPU, 표시 스케일 둘 다1.4로 맞췄다. 원본 그림의 바이트는 수정하지 않았다. 최종 판정과 정확히 맞는 타격 포즈, 부드러운 중간 동작, 별도 사망/걷기는 부족하므로 전투 완성 검증은 아니다.
