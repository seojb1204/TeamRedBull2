## 1. 결과와 근본 원인

이번 작업은 제품의 DB 또는 LIVE 오류를 재현해 실패한 것이 아니다. **기준이 되는 Windows 최종 원클릭 ZIP을 현재 Linux 실행 환경에서 읽을 수 없어 사용자 지시에 따라 중단했다.**

사용자가 지정한 최종 ZIP은 Windows PC에 있다. 현재 환경의 운영체제는 POSIX이며 지정 파일과 일반적인 Windows 드라이브 마운트 후보, 현재 작업 공간·출력 폴더의 동일 파일명에 대한 접근 확인은 모두 false였다. 개인 계정명이 포함된 Windows 경로는 기록하지 않는다.

원본 ZIP을 읽지 못했으므로 원본 SHA256, 내부 파일 구성, 실제 포함된 DB UI 버전을 확인할 수 없었다. 사용자가 “ZIP에 접근할 수 없다면 중단”이라고 명시하여 추가 구현·패키징을 하지 않았다.

## 2. 실제 진행한 작업

- 기존 로컬 변경을 확인하고 보존했다.
- origin/main을 fetch했으며 준비 기준은 위 SHA였다.
- 당시 승인 범위에서 별도 로컬 worktree와 `feat/dda-db-exhibit-ui-20261124` 브랜치를 준비했다. 해당 UI 브랜치에는 작업 커밋·Push·PR·main 병합을 하지 않았다. 이번 보고 작업에서 새 브랜치를 만들지는 않는다.
- `Tools/DdaLab/database.js`, `index.html`, `monitor.js`, 집계·송신 진단 계약, 기존 UI·회귀 테스트와 `package_windows.py`를 읽고 의존성을 검토했다.
- Node.js, Chromium, Python Playwright 사용 가능 여부를 확인했다. UI 자동 테스트나 실제 Windows 실행 검증을 완료했다는 뜻은 아니다.
- 원본 ZIP 접근 불가를 확인한 뒤 작업을 중단했다.

## 3. 실행 중 발생한 부수 오류

| 오류 | 처리와 영향 |
|---|---|
| `No usable execution environment is available` | 환경 시작 직후 한 명령이 실패했다. 환경 준비 후 준비 작업을 실행했다. 제품 오류가 아니다. |
| ZIP 경로 확인용 Python 입력의 `SyntaxError: unterminated string literal` | 문자열 종료 문법을 수정해 재실행했다. 파일 수정은 없었고 최종 접근 확인은 false였다. 접근 불가의 근본 원인이 아니다. |
| GitHub API GET 및 Issue POST의 `Forbidden` | 이후 현황을 새 Issue로 공유하려 했으나 두 요청이 거부되었다. Issue 생성은 실패했으며 Issue 번호는 없다. 응답만으로 토큰 권한·게이트웨이·환경 정책 중 어느 것이 원인인지 확정할 수 없다. |

Issue 생성 실패 후 사용자가 새 Issue·PR·브랜치 생성 대신 기존 문서 브랜치의 이 파일로 보고하도록 지시했다. 이번에는 기존 브랜치만 사용하며 Issue 생성을 재시도하지 않는다.

## 6. 안전한 재개 조건과 남은 작업

1. 실제 원본 ZIP에 접근 가능한 Windows 작업 환경 또는 사용자가 승인한 파일 전달 경로를 확보한다. Windows 경로만 전달받았다는 이유로 접근 가능하다고 처리하지 않는다.
2. 원본 SHA256을 기록하고 별도 작업 폴더에 복사·해제한다. 원본과 기존 ZIP은 덮어쓰지 않고 설정·비밀값을 출력하지 않는다.
3. 원본 ZIP 내부 버전을 기준으로 허용된 DDA-Lab UI만 수정한다. 게임·알고리즘·설정·실행 구조는 보존하며 Unity를 재빌드하지 않는다.
4. 출처 구분, 소표본·무기록, 조회 실패, 송신 성공·실패·미수집, KST, 상세 진단 접기, 새로고침 및 LIVE 회귀를 검증한다. 새 운영 DB 테스트 데이터를 생성하지 않는다.
5. 다른 파일명으로 개선판 ZIP을 생성한다. 전체 파일 해시를 비교해 게임 EXE와 Unity 데이터의 바이트 동일성을 확인한다. 필요한 무결성 manifest 갱신 여부는 실제 패키지의 검증 방식에 맞춰 사전 검토하고 검증을 우회하지 않는다.
6. 실제 Windows에서 무설치 실행·게임·LIVE·DB 표시를 확인하고 ZIP 경로·SHA256·검증 범위·미검증을 보고한다.

이 보고서는 현황 기록이다. UI 재작업·운영 DB 변경·게임 빌드·배포를 수행하거나 승인한 문서가 아니다. 조사하지 않은 원인은 추측으로 확정하지 않는다.
