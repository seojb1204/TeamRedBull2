# 강화 전용 화면 (2026-11-15)

로비에는 `강화하기` 진입만 두고 선택 중에는 로비 Canvas 페이지를 숨깁니다.
전용 화면에서 기존 제시 카드 3장의 효과·수치·보유량·가격을 비교하고 하나를 선택합니다.
취소/다시 열기는 같은 offer와 골드를 유지하며, 선택 완료 후 기존 연출을 거쳐 로비로 돌아갑니다.
재화, 카드 풀, 확률, 구매 제한, 세이브 및 클라우드 데이터 로직은 변경하지 않았습니다.
