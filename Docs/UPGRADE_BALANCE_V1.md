# 강화 16종 · 성장 설계 v1 (2026-11-15)

사용자의 강화·레벨디자인 적용 요청을 위한 시험판 수치입니다. 실제 사람 대상 재미·장기 균형 검증 완료를 뜻하지 않습니다.

- R은 게이지100 소모형이다. R쿨감은 만들지 않고 적중 게이지 획득을 강화한다. 패링+15와 시간 경과 충전은 변하지 않는다.
- 흐름 회수: 3초 발동 간격, 쿨타임 최저0, 궁 게이지 환급 없음. 반격은 중복 적립하지 않고 갱신, 빗나가면3초 만료 전 유지, 첫 명중에 소모.
- 궁극기 강화는 파네스 투사체5개에도 적용되며 회복·경직·무적 시간은 증폭하지 않는다.
- 기본 방어 계산: 기존 한 번 최대HP30% 제한 후 피해감소 적용. 최대체력과 방어를 별도 설명한다. 무적·패링 타이밍·공격 속도는 변경하지 않았다.
- 같은 스탯은 합산한다. Q/W/E 쿨감 최대18%로 각각4.92/8.2/12.3초. 이동속도 최대+12%, 방어 최대9%.

## 저장 보존

기존6종 ID와 저장 형식을 유지. 기존 중첩은 새 구매상한을 넘어도 삭제/하향하지 않는다. 새 상한은 추가 구매에만 적용. 기존 QWE 피해강화는 +5%p에서+8%p로 상향된다. 이전 공격/체력 강화 레벨도 그대로 적용한다. 기존 골드·클리어·DDA 기억을 초기화하지 않는다.

구매 시 분리된 복사본을 먼저 저장한 뒤 라이브 상태에 반영하는 거래 순서를 유지한다. 신규 카드16종 재시작 보존, 저장 실패, 중복 구매, 기존 초과중첩 회귀 검사 포함.

## 선택·성장 템포

- 로비→강화하기→3장 선택→보스전→결과 구조, 전투당1장, 건너뛰기 가능.
- 가능한 경우 공격/생존/운용 각1장, 표시 순서는 섞는다. 해금 전/최대치 도달 카드는 제시하지 않는다.
- 후보가1~2개만 남으면 해당 개수만 표시. 모두 완료되면 안내하고 빈 화면에 들어가지 않는다.
- 유효한 offer는 취소·재열기·재시작해도 동일하다. 카드 수 제한은 실제 가용 카드에만 따른다.
- 가격80→100→120→140→160→180, 이후180상한. 기존 승패 보상식은 보존한다.
- 목표: 의미 있는 패배2~3회 또는 첫 승리1회 안팎 강화. 이는 튜닝 목표이며 모든 진행 구간에서 달성된 측정 결과가 아니다.

## 레벨디자인 적용 범위

기존5보스 순서를 보존하며 승리 시 카드군 해금으로 복잡도를 점진적으로 소개한다. 아라쿠스 기본 방어/공격→파네스 위치선정/패링→아디쿠스 대상우선순위→에텔로스 종합→카로스 숙련자 도전. 보스HP·공격기믹·공간·패턴 출현 순서를 이 PR에서 임의 변경하지 않았다. 실제 씬의 HP override는 Windows 시험에서 별도 확인한다.

## DDA와 측정

`LobbyCards.Power`에 신규 옵션을 반영하되 기존 정책·학습 기록을 초기화하지 않고 직접 난이도 가산도 하지 않는다. 첫 전투는 그대로 기본난이도. 강화 직후 DDA가 효과를 상쇄하지 않는지 고정시드/DDA OFF 비교 후 ON에서 재평가해야 한다. 현재는 그 장기 공정성을 입증한 단계가 아니다.

무강화/공격형/생존형/패링형에 동일 시드·동일 입력정책으로 승률, 클리어시간, 피격, 포션, 패링당 이득, 스킬피해 비중을 비교한다. 사람 대상 효과 설명 정답률·선택 이유·체감 차이도 확인한다. AI 승률은 재미의 증거가 아니다.
