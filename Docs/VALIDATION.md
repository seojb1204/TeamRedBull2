# 0.5 제작 기반 검증

## 완료 범위

0.4에서 보스 패턴 실행/상태, DDA 세션, 보상 정산을 별도 소유 객체로 분리했다. 팀 제공 아라쿠스14시트를 임포트하고 플레이어/아라쿠스 Prefab, 두 AnimatorController와25클립, 보스5종 Inspector 데이터, 실제Production씬을 연결했다. 타이틀·로비·카드·전투HUD·결과·엔딩·일시정지는 uGUI다.

## 실제 검사

Windows / Unity6000.4.0f1 / Mono64 / Built-in.

- 기존 로직114 assertions 통과. 같은 이름 검사를 유지하며 반복 정산 시 기존 결과 보존 조건을 강화했다.
- FoundationSetup.Verify: 보스SO 깊은복사 원본불변,클립 스프라이트참조,컨트롤러/프리팹/Production씬 참조 통과.
- Unity Windows 빌드 성공, 컴파일 오류 없음.
- 실제 Windows 플레이어 로비 통합검사19개 통과(exit0): 기본14개에 씬/Animator/uGUI직렬화이벤트3개와 체력바2개를 추가했고, 직렬화된 카드 버튼 이벤트를 호출해 구매/저장을 교차 확인했다.
- 실제 자동 전투10초 실행·캡처·제한종료. 체력 보정 없음. 정상 규칙 클리어/사람 조작 검증은 아님.
- 별도 테스트 저장 사용. 로비검사는 테스트Gold1000·고정후보·강제실패 정산을 사용하며 보고서에 표시한다.
- 생성과정에서 NPOT 리사이즈,StreamingAssets 이미지 임포터 차이,실패 생성본 복구 문제를 수정하고 재빌드했다.

## 미완료·미검증

- 원본5보스 전체패턴·기믹,신규DDA18특징모델·prior/rule,정확한 입력재생/난수시드 비교는 미완료.
- 도움말·설정·기록은 아직 IMGUI. 플레이어 입력/전투는 아직 TowerGame. 배경은 절차적이고 씬Collider는 참고용이다.
- 여러 기본패턴을 기존6종으로 유지했다. 새스프라이트가 있다고 퀵스텝/복합방패/분노 등이 구현된 것으로 보고하지 않는다.
- Animator는 판정시계에 맞춰 준비/실행/회수 포즈를 고르는 기반이다. 중간프레임·타별 정확한 무기궤적/히트박스·피격실루엣은 추가 작업이다.
- 사람의 재미·조작감·소리청취·장기밸런스·다중해상도·성능·정상규칙 아라쿠스완주 미검증.

이번 결과는 M0와 M1 제작기반 첫 단계다. 팀의 최종승인이나 M1~M4 전체완료가 아니다. 충돌 기믹 보류와 구조/에셋 우선 진행은 사용자가 명시 선택했다.

## 재현

Unity 메뉴 Reversal Tower/Create Production Foundation, 빌드 FoundationSetup.Build. Production씬이 있으면 검사만 하며 편집내용을 재생성하지 않는다. Verify-Logic.ps1은 셰임 검사로 Unity 렌더링 검사가 아니다.

Windows 실행: 보통 인자 없이 exe. 자동검사에만 -towerLobbySmoke 또는 -towerDemo, -towerDataRoot <독립폴더>, -towerReport <파일>, -towerCapture <PNG>, -towerAutoSeconds <제한>을 사용한다.

기존0.4/v1,v2 저장형식과 카드규칙을 유지한다. 새DDA모델 이행은 저장버전을 별도로 설계한 뒤 수행한다. 로컬 baseline커밋과0.4배포ZIP으로 복구할 수 있다.

공개 업로드 검토에서 ProjectSettings의 기기용 passcode 필드가 노출 위험으로 거절되어 PS4/인증 비밀번호 필드를 빈 값으로 정리했다. 0.4 공개 기준 스냅샷에도 동일한 정리를 적용하며 원래 로컬0.4는 변경하지 않는다. Windows 전투 설정이나 라이선스 우회는 하지 않았다.
