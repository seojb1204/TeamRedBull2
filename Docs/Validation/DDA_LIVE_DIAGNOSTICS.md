# 실시간 DDA 판단근거 진단

F8의 기존 레벨·이번 판·기억/다음 판 표는 유지하고 아래에 **직전 패턴 선택 당시** 후보별 패링/회피/피격/제외, 기본 가중치, 연습 배수, 최종 가중치, 정규화 선택 확률, 선택 여부와 이유를 추가한다. 매 프레임 다시 추첨하지 않으며 진행 중 공격을 바꾸지 않는다. 결과 화면에서도 마지막 선택을 보존한다. 후보가 아닌 거리/페이즈/쿨다운 제외 패턴은 이 표에 나타나지 않는다. 실제 등장 빈도는 확률과 같지 않을 수 있다.

일반 플레이와 격리 테스트 모두 기존 SaveStore.Root 아래 DdaDecisions/<전투 GUID>.csv에 선택 단위 행을 추가한다. 전투마다 고유 파일로 기록하며 기존 파일을 삭제/교체하지 않는다. 개인 식별자나 DB 데이터 없이 전투 판단 통계만 기록하며 CloudSync 이벤트를 호출하지 않는다. 한 전투 파일은 16MB를 넘으면 추가 기록을 중단하고 F8에 알린다. I/O 실패도 화면에 알리고 전투는 계속한다. 메모리는 기존128후보행 제한을 유지한다. 파일이 선택 직후 기록되어 일반 종료 전에도 이미 완료된 선택 기록이 남는다. 장기 누적 파일 정리는 자동으로 하지 않는다.

검증: DDA185검사 (기존178+가중치/스냅샷/수동 CSV/컬럼/행수/I/O실패/원본보존7). 별도 통합 결과는 작업 보고 참조. 실제 Unity UI 컴파일/Windows 캡처·F8 스크롤·크기변경과 수동 입력·로그 경로 검증은 아직 필요하다. HEADLESS 검사를 UI 렌더링 검증으로 주장하지 않는다. 전투 알고리즘·DB·저장 스키마·아트 변경 없음.
