## 빌드 차단 분석
사용자 PC의 Hub 라이선스 로그에는 정상 handshake 이력이 있지만 자동 실행 Editor는 LicenseClient 연결 거부 및 WMI assertion을 기록했다. 자동 실행 환경의 IPC/시스템 정보 접근 차이가 원인일 가능성이 있으나 확정하지 않았다. 라이선스가 없거나 만료됐다고 단정하지 않는다. 라이선스/계정 파일 삭제, 재활성화, 보안 설정 변경 또는 실행 권한 우회는 하지 않았다.
공식 배치 옵션: https://docs.unity.com/en-us/engine/6000.0/manual/unity-editor/command-line-arguments/editor
클라이언트 진단: https://docs.unity.com/en-us/licensing-server/troubleshooting-client

## 배포 수정
Publish-WindowsRelease.ps1은 Get-WindowsReleaseFiles.ps1을 통해 Unity 6000.4 Windows x64 Mono의 필수 파일을 검사한다. exe/UnityPlayer/dstorage/dstoragecore/Mono runtime/globalgamemanagers 중 누락 또는 빈 파일이 있으면 압축 전 중단한다. 기존 허용 파일 목록에 DStorage 2개를 추가한다.
Tests/Test-WindowsPackage.ps1: 6개 필수 파일 각각 누락·빈 파일 거부(12), ZIP 압축 해제 후 6개 파일 해시 일치(6), 관계없는 루트 파일 제외(1), 총19개. 테스트용 가짜 바이트를 사용하며 실제 플레이 성공과 구분한다.
기존 Publish의 최신 main/깨끗한 작업 폴더/새 exe 검사와 공개 전 검증 조건은 유지한다.
