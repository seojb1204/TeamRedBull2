# 화면 학습 자동플레이: 현재 결과 (2026-11-14)

실제 Unity 화면을 보고 조작하고, 실제 시연·보상으로 학습한 뒤 별도 기록을 남기는 **실행 가능한 실험 에이전트**다. 일반적으로 보스를 깨거나 재미를 정확히 판정하는 사람 같은 AI는 아직 아니다. 내부 보스 타이머/좌표는 정책 입력으로 쓰지 않는다. 픽셀 검출 특징과 자신의 입력 이력으로 행동한다.

## 실제 검증
- Unity6000.4.0f1 독립 빌드, DB 설정 없는 격리 저장, DDA OFF.
- 숨김 부모창 + 메시지 처리 + 직접 Camera RenderTexture 경로로 실제 스프라이트 관찰. HUD/IMGUI 제외.
- 정상 실행18회: 시연2 + 초기비교6 + 통합실행기smoke1 + 일반RL훈련/평가5 + 시연보존RL훈련/평가4. 전부 패배. 검정화면·초기숨김 실패는 별도 보존하고 학습에서 제외했다.
- Python46개 및 C# 브리지 기본/오프스크린 각24개 검사. 실제 통합 실행기smoke 완료.

## 재현과 증거
- `ITERATION4_COMPLETE.md/json`: 모방 및 일반RL 실패까지 모두 보존.
- `ITERATION4_ANCHOR.md/json`: 보존형 보조RL2훈련+2개발검증.
- `DEMONSTRATION_RETENTION.md`: 훈련 명령, 시연 보조의 정의, 패링 단계 과제 설계.
- `run_campaign.py --hidden --offscreen`: 안전검사를 통과한 독립 Windows 빌드만 실행. 소유 실험 프로세스만 정리하고 일반 게임/데이터는 건드리지 않는다.

원본 모방모델·실패한 일반RL모델·새 보조RL모델과 원시기록을 모두 보존했다. 평가 중 모델 해시 불변 확인. 사용자 게임을 위해 모든 실험 프로세스를 종료했으며 추가 실행하지 않는다.

다음 과제는 새로운 미사용 평가시드에서 후보와 기준선을 비교하고, 성공 패링 시연이 포함된 별도 연습 과제를 실제 구현하는 것이다. 현재 게임 재미/장기 밸런스 판정과 다섯 보스 전부에 대한 시각 학습은 미완료다.
