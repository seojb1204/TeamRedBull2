# 제한 개선: 시연 보존형 학습과 패링 단계 과제

## 동기
원본 모방모델의 별도 시드 평균 보스 피해430에 비해 일반 Q 추가학습 뒤75로 하락했다. 이는 단순 희소보상 학습이 기존 공격 행동을 잃을 수 있음을 보여준 소규모 사례이며 일반적 RL 한계의 증명은 아니다. 실패모델과 기록은 보존한다.

## 이번 비교
실제 시연에서 같은 시각 상태에80% 이상 등장한 행동에 **soft large-margin 시연 보조학습**을 적용한다. 보상 업데이트를 그대로 수행하되 해당 행동 가치가 다른 행동 최대값+0.05보다 낮으면 차이의20%만 되돌린다. 강제 행동/실시간 규칙 fallback이 아니다. 처음 보는 상태는 기존 보상학습을 따른다. 이 보조가 유효하게 새로운 전략을 배우거나 교사보다 나아졌다는 의미는 아니다.80%는 시연 내 빈도이지 보정된 성공 확률이 아니다.

```powershell
python run_campaign.py --exe <independent.exe> --output <new-training> --policy tabular-v3 --train --checkpoint <copy-of-original-imitation.json> --anchor-checkpoint <original-imitation.json> --seed 601 --episodes 2 --epsilon .2 --seconds 60 --hidden --offscreen
python run_campaign.py --exe <independent.exe> --output <new-evaluation> --policy tabular-v3 --checkpoint <trained-copy.json> --seed 401 --episodes 2 --seconds 60 --hidden --offscreen
```

사전고정:2훈련+2평가, 훈련601/602, 평가401/402. 기존무작위·규칙·모방·일반RL의401/402 결과와 비교한다. 정책 개선 방향을 이미 이 평가 결과로 골랐으므로 이2시드는 이제 **개발 검증 시드**이며 독립 최종 일반화 증거로 반복 제시하지 않는다. 유효 후보가 나온 뒤 새로운 시드를 별도로 고정해야 한다. 평가에서는 anchor를 적용하지 않고 체크포인트를 변경하지 않는다.

## 패링 단계 과제(설계, 아직 실게임 구현 아님)
1. 동일 렌더 경로에서 경고가 시작/유지/종료되는 실제 화면 연속샘플을 수집하고, 플레이어·보스 검출 실패와 반짝임 오검출을 먼저 평가한다.
2. 접근/바라보기를 고정된 시연으로 충분히 배운 뒤, 경고 시점과 자기 입력 이력만으로 패링 타이밍을 배우는 독립 연습 장면을 만든다. 기존 본편을 바꾸거나 연습성과를 본편승률로 기록하지 않는다.
3. 성공 패링이 충분히 들어있는 시연과 실패시연을 함께 기록한다. 현재 시연은 성공 패링이 희소해 '패링을 배웠다'고 말할 수 없다.
4. 연습 전용 보상은 실제 성공패링을 채점에만 사용하고 정책입력에 내부 타이머/다음 공격 정보를 넣지 않는다.
5. 새 고정시드에서 패링성공률·헛패링·받은피해를 비교한 후에만 전체 보스전으로 옮긴다. 재미와 체감 공정성은 사람 평가를 별도로 유지한다.
