# Source recordings for the boss combat SFX

Recorded sounds that `Tools/sfx/generate_boss_sfx.py` cuts, re-pitches, reverses,
layers and reverberates into `Assets/StreamingAssets/Audio/sfx_*.wav`.

All files below are **CC0 (public domain)**. They come from Freesound via the
Sonic Pi sample library (`sonic-pi-net/sonic-pi`, `etc/samples`, whose README states
that every non-Arovane sample there is a Freesound recording released under CC0).
Here they are converted to 44.1 kHz mono FLAC; nothing else is changed.
Attribution is not required by CC0 and is kept voluntarily.
