내용: 승인된 8프레임 샘플 + 새 16프레임 시트 3장, 총 56 생성 키포즈.
미리보기 16상태: 대기/순간이동/피격/그로기/사망 + 공격 11종.
성운은 결계의 시전 자세를, 분신은 왜곡의 팔 펼침/분해 자세를 공유합니다. 아직 전용 클립 완성본이 아닙니다.
마법 효과는 미리보기용 Canvas 코드입니다. 문서의 최종 이펙트 13종 PNG/타일 세트, 공중 발판, 분신 전용 아트까지 완성했다는 의미가 아닙니다.

제작: 내장 image_gen 사용. 승인된 sprite-sheet를 디자인 기준으로 참조.
공통 프롬프트: 얼굴 없는 보라/남색 후드, 금색 룬과 체인/클래스프, 찢어진 로브, 맨발, 금색 해십자 지팡이 보존. 오른쪽 5~10도 측면. 투명 배경, 블러 없는 픽셀아트. 1536x1536, 4열4행, 행마다4포즈, 동일 발 기준점, 본체와 이펙트 분리.
basic: 순간이동/피격/그로기/사망.
spells-a: 부채꼴 산탄/굴절 광탄/빛 기둥/징벌선.
spells-b: 잔향/업화/결계·성운/왜곡·분신.

검증: HTML의 동일 Canvas 소스를 독립 렌더러에서 실행, 16상태 x4시점=64회 렌더링 확인. SizeComparison 및 3개 동작 캡처 시각 확인. 브라우저 UI 실행 검증은 하지 않았습니다.
