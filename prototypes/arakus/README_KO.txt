아라쿠스 2D 도트 아트 시안
2026-11-05 / Unity 6000.4.0f1

바로 보기
CharacterPreview.html 하나를 브라우저에서 엽니다.
캐릭터 / 소품 / 이펙트 메뉴와 일시정지, 프레임 이동, 배속, 정수 확대, 좌우 반전을 제공합니다.
화면의 192x192는 여백 포함 캔버스이며 서 있는 기준 자세의 높이는 약 88px입니다.
시점은 오른쪽 측면에서 카메라 쪽으로 5~10도 돌아 양팔이 읽히는 방향을 시각적으로 지정했습니다.
이미지 생성 방식이므로 측정된 3D 카메라 각도가 아닙니다.

포함 내용
캐릭터 16종 77프레임: 일반 거검 공격, 방패 내려찍기, 발차기, 퀵스텝,
양손 거검, 방패 투척 후 돌진 베기, 방패 돌진, 투척 후 도약 내려찍기,
일대 휩쓸기, 분노, 기믹 돌진, 대기, 걷기, 패링 경직, 그로기, 사망.
소품 2종 6프레임: 회전 방패 4장, 기둥 정상/파손 2장.
이펙트 16종 96프레임: 문서의 11개 요청 묶음을 검풍/바람, 가로/세로/충전,
흰 오라/충격파/붉은 오라 등 독립적으로 사용할 요소로 나눴습니다.
합계 34종 179프레임, 동작별 가로 PNG 시트 34장과 개별 PNG 179장입니다.

규격
캐릭터와 소품: 한 칸 192x192 투명 PNG. 접지 기준선 위쪽 원점 y=160.
이펙트: 한 칸 384x384 투명 PNG. 기준선 y=320.
캐릭터 16종 전체에 공통 32색, 이진 알파(0/255), 최근접 축소, Point 필터,
압축 없음, 밉맵 없음, 40 PPU를 사용합니다. 1m=40px인 문서의 가정에 맞췄습니다.
팔레트는 Source/palette.json, 정확한 프레임 시간은 Assets/Arakus/clip_manifest.json입니다.
기존 주인공 게임 적용본의 75 PPU와 같은 설정이 아니므로 실제 게임 통합 시 상대 크기를 확인해야 합니다.

방패와 타이밍
투척 두 패턴의 첫 두 그림은 픽셀 단위로 같습니다. 분기 후에는 서로 다른 동작입니다.
양손 거검은 등에 방패를 메고, 투척 중에는 방패가 몸에서 사라지며 마지막에 회수합니다.
사망은 첫 두 프레임에 방패를 유지하고 이후 몸에서 사라집니다. 떨어지는 방패의 궤적은 게임에서 별도 연결합니다.
방패 내려찍기는 0.85초에 지면 충격 자세가 나옵니다.
투척 후 돌진의 도착 시각은 실제 거리에 따라 달라집니다. 미리보기는 예시 시간입니다.
분노의 붉은 몸 색은 그리지 않았습니다. 게임에서 색을 적용하도록 일반 피부색을 유지했습니다.
돌진 달리기와 그로기 흔들림의 반복 구간, 방패 회수 시점은 실제 패턴 로직에서 연결해야 합니다.
미리보기는 각 키포즈를 순서대로 보여주며, 단발 동작 끝에서는 마지막 자세를 유지합니다.

Unity에서 확인
이 폴더를 Unity Hub에 추가하고 Unity 6000.4.0f1로 엽니다.
Assets/Arakus/ArakusPreview.unity에서 Play를 누릅니다.
ArakusArtPreview.prefab, Arakus.controller와 34개 .anim을 포함합니다.
검수 Prefab의 Animator는 수동 프레임 표시와 충돌하지 않도록 비활성화되어 있습니다.
검수 화면은 별도 ArakusPreview 스크립트로 재생하며, 게임 연결 시 해당 검수 스크립트 대신 게임 제어기를 사용해야 합니다.
각 .anim의 sample rate 1000은 밀리초 교체 시점 저장용입니다. 실제 그림 수는 179장입니다.
Arakus/Build and verify preview 메뉴는 이 별도 프로젝트의 검수 자산을 갱신합니다.

제작 자료와 한계
사용자가 앞서 제공한 레기온 전사 디자인 시트와 아라쿠스 DOCX의 외형/동작 설명을 기준으로 제작했습니다.
문서가 가리키는 아라쿠스 원화/도트 이미지 두 장은 이번 작업에 제공되지 않아 직접 대조하지 못했습니다.
내장 image_gen으로 생성한 2D 이미지이며 Blender 모델이나 리그, Aseprite 수작업 원본은 없습니다.
Source/Generated는 최종 선택된 생성 원본, Source/generation_prompts.json은 공통 지시와 자세별 지시 세트입니다.
Source/extract.ps1은 프레임 분리·발 기준점·공통 팔레트·시트 출력을 수행합니다.
동작은 문서의 핵심 자세 중심입니다. 최종 수작업 애니메이션과 동일한 세부 일관성을 보장하지 않습니다.
프레임 사이 근육·투구·검·방패 디테일과 각도의 미세한 차이는 팀 검수가 필요합니다.

캐릭터 전체 공통 32색, 투척 준비 두 그림 동일 검사.
PreviewLogicValidation.json: 가상 화면 요소로 재생·멈춤·반전·확대·단발 종료·반복 검사.
실제 브라우저에서 직접 버튼을 누른 검사는 아닙니다.
Unity 컴파일, 34개 시트 분할/클립 길이/실제 클립 샘플링, 반전 출력과 사망 마지막 자세를 검사했습니다.
Review/Unity_*.png는 실제 Unity 카메라 출력입니다.
기존 게임 씬·Prefab·공통 코드와 DB 설정은 수정하지 않았습니다.
전투 판정, 이동·점프, 분노 버프, 기둥 기믹, 실제 이펙트 결합은 미구현입니다.
수동 플레이 완주와 Windows 실행 파일 빌드는 미검증입니다.

배포 파일
Arakus.zip은 생성 원본까지 포함한 보존본입니다.
Arakus_Unity.zip은 Assets/Packages/ProjectSettings와 안내문을 포함한 가벼운 검수 프로젝트입니다.
저장소에는 가벼운 검수 ZIP과 단일 HTML, 제작 지시·코드·검증 자료를 공유하며 원본 생성 이미지는 보존본에 있습니다.
main 직접 push/자동 병합을 하지 않고 별도 브랜치와 PR로 공유합니다. 검토자는 팀에서 지정합니다.
